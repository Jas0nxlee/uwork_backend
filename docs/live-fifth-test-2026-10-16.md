# 第五批真实功能补测：2026-10-16

继续测试现有后端未覆盖的参数、异常与持久化分支。企微、外部 MCP 和网盘按用户要求排除；没有用模拟通过替代外部验收。业务流程通过实际 TCP HTTP 和磁盘 SQLite 执行，明确标注的初始化、故障注入和测试时钟仅作用于独立临时实例。

## 发现、修复与复测

- 初始化：原实现先提交随机密码账户，再创建登录凭据文件。已有同名文件或目录错误会留下无法取得随机密码的账户。现先以 0600 独占创建并持久化凭据，再创建账户；提交前失败只删除自有新文件，提交后注记失败保留有效登录材料。五项子进程回归验证拒绝覆盖、无效目录、失败清理、正常初始化与重复运行，以及提交后注记故障仍可实际登录。没有宣称跨文件系统与数据库的断电原子性。
- 模型目录：客户端曾列出凭据不存在或已吊销的模型。现仅列出引用本组织 active 凭据且满足原授权条件的模型；管理端保留记录供修复。三项回归与生产构建的独立 HTTP 矩阵通过；轮换后恢复目录，旧缓存不绕过当前授权。目录检查元数据，不保证密文可解密或供应商健康。
- 流式错误：HTTP 200 SSE 的非空顶层 error 曾被 schema 丢弃，形成空成功、错误结算与缓存；命名 event:error 也可能被忽略。现在返回稳定错误，不转发供应商错误正文；已派发但无法核实用量仍为 uncertain，不缓存成功。error:null 正常兼容。
- 流式终态：首个 DONE 后曾继续等待连接结束并处理额外帧，导致成功流超时或混入终态后的内容。现立即结束读取并关闭上游。受控上游保持连接打开的用例约 3 毫秒结束；后续正文、垃圾数据与错误事件均忽略。
- 请求准入：额度预占提交后、持久请求标记写入失败会留下未调用模型的预占。现两项写入在同一事务提交；临时库触发器先复现供应商零调用但账目残留，再验证修后同时回滚，恢复存储后原键仅派发一次并正常结算。

上述问题均保留修前失败和修后通过证据。网关另覆盖 429、500、断开、响应大小、用量越界、多字节/CRLF 分片、缺终态、无 usage 估算与子进程真实 SIGKILL 后文件库恢复；失败/重启后的同键不重复派发。新增源码经独立审查。

## 模型管理与真实供应商

独立生产构建实例的模型管理矩阵 65/65，通过 191 次脱敏 HTTP 请求、12 次受控模型生成与一次目录探测，未产生供应商费用。覆盖角色、跨组织引用、修订竞争、非法更新原子性、价格取整、上下文/输出限制、视觉与思考开关、已发布 Agent 引用当前模型参数、停用/范围/凭据吊销/轮换及缓存授权。三轮夹具均清理自身资源，六个会话退出。

主实例使用原凭据引用创建仅 owner 可见的临时模型，实际调用已配置供应商两次：16×16 红色 PNG 返回“红色”；reasoning_effort=high 的简单算术请求返回“5”。它们证明该供应商接受图像和思考参数并返回预期基础结果，不构成复杂视觉/推理能力基准。实际输入 271、输出 143 Token，内部计量新增 414 Credit，两条均 settled；供应商发票未对账。临时模型已停用、会话退出，原模型、Agent v4 和安全配置保持不变。

## 按规格补齐剩余有限分支

对照能力图、13 份模块规格、实施计划、验收台账与前四批原始断言，追加五组本地可执行的不同分支：账目核实的金额/并发/权限边界、客户端事件首写与用户/组织隔离、通知 pending 重启与 Feishu 载荷、夏令时 Cron UTC 投影，以及数据集数量/长度和 Unicode/空值/失败任务评分。五组追加九项自动测试全部通过，没有发现新的产品缺陷；具体结果在最终验收台账与 ignored 覆盖审计记录中逐项对应；既有普通成功路径没有重复算作新增覆盖。

客户端事件同用户同键不同内容保持首条，跨用户/组织互不吞事件；合法长度上限接受，非法字段不新增记录。数据集 50 条接受、51/0 条拒绝；输入/预期 10000 字符接受、超限拒绝；六次受控生成的 exact/contains、Unicode、空值和失败任务评分得到 4/6，失败任务即使预期为空也不通过。评测 succeeded 表示汇总完成。

账目核实追加 24 个有名检查：0/预占额边界、超额及非 uncertain 状态拒绝、两路并发仅一次成功/审计、角色/设备/跨组织拒绝与非法正文原子性。只核实明确初始化的临时账目，没有接触真实 uncertain 记录。通知第一次受控 503 后正常关闭再打开磁盘库，attempts/next_at 保留；截止前不重试、精确截止成功投递，模型只调用一次；Feishu 成功输出和失败任务载荷均验证。Cron 以五个固定 UTC 时刻验证纽约跳时/回拨及创建时点相关的锁定库语义，并用 HTTP 保存、重启读取 disabled 调度；没有宣称真实等待夏令时或制定新的单次/双次业务政策。

最终 **224 项测试通过，失败/跳过/取消均为 0**，类型、Lint、格式、页面能力台账和生产构建通过。
