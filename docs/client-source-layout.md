# 客户端源码与开发范围

按用户 2026-10-17 指示，UWork 客户端源码纳入本仓库的 `clients/uwork/`，后续代码修改、依赖安装、构建和联动测试均针对该目录。原客户端 checkout 仅作为只读来源，不再修改、构建或清理其内容。

初始快照采用已适配后端的客户端 Git HEAD `f59e74dce7ccc8376e0598d5490de43790b14c7f` 的全部受版本控制文件，保留 LICENSE、NOTICE、THIRD-PARTY-NOTICES、工作区结构及 AGENTS/架构治理规范。使用干净源码归档，不带原目录的 `.git`、凭据、`.env`、用户数据、依赖和生成物；不以新拉取的上游 main 覆盖已有后端适配。

客户端作为本仓库内的完整工作区维护，由父仓库 Git 统一记录变更，不创建嵌套 Git 仓库或 gitlink。运行其命令时进入 `clients/uwork/`，使用该工作区锁定的 Node/pnpm；客户端内部工作区引用继续指向其自身 packages/apps。原有后端 SDK/跨源码验证默认定位该内置路径，显式路径覆盖只用于验证工具兼容。

后端 Docker 构建上下文排除 `clients/`；客户端仍通过自身构建命令产出，避免向后端构建器传输桌面依赖、测试应用和无关源码。

独立临时数据根承载合成身份、客户端状态与测试后端；真实桌面用户目录、主后端账本及原仓库配置不作为测试写入目标。当前排除企微扫码、外部 MCP 和网盘。源码联调、打包 CLI stdio、真实 Electron 联动分别记录证据，不能相互替代平台安装验收。
