# 原管理端异常事件与只读页面加载

独立console模式，按原catalog源码生成导航清单（外部集成页按排除范围跳过），按原forms源码生成客户端定制11标签清单，不硬编码替代产品页面。1440/768/320三个视口分别通过原菜单和标签按钮加载，等待对应真实HTTP成功与原页面就绪。

浏览器通过browser-harness的CDP Runtime/Log/Network事件被动采集；每轮先在about:blank发一条明确校准console.error并确认收到，再清空校准事件，原产品运行窗口中要求未捕获异常、console.error/assert/warning、其他浏览器error日志为0。原匿名auth/me 401是登录探测，单独列为预期网络结果；不以它掩盖其他HTTP或JS错误。观察器不能修改原业务响应/store或替代页面调用。

只补此前未采集的console验收维度，不重复原已通过的创建/发布/执行/删除流程；三轮只有读API和必要登录，模型/配置/成员/凭据/账本行均保持，供应商0。排除外部MCP、网盘页面/操作和发布后多系统客户端。
