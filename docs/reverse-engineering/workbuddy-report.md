**完整服务端复现、管理 Web、UWork 客户端适配尚未实现。** 目前产出用于确定模块边界、规格与后续验收，不构成产品上线或完整复现的证明。

## 已明确的规则与限制

以下来自页面说明或发布代码。除单独声明外，均未通过写入/多身份/真实客户端试验验证服务端执行效果。

### 身份、组织与席位

当前租户采用企微接入模式。组织架构页面说明只查看分配过席位或超管角色的成员；角色成员增删、席位分配/移除要求前往企微管理后台。不能据此宣称原站拥有当前模式下的本地组织 CRUD。

本轮只证明既有会话可读取当前账号授权范围，未重新扫码，也未验证过期、重放、不同管理员/成员、其他企业或 UWork 各组织回调。自有后台需要自己的信任关系与回调配置；现有浏览器 Cookie 不是部署凭据。

### 模型、技能、专家与连接器策略

- 模型页面说明：先以可见且启用的模型为基准，再应用限定策略，随后移除被屏蔽的模型；屏蔽优先。未来新增内置模型的默认启用策略不修改已有模型，也不影响自定义模型。
- 技能/专家页面说明：多条限定策略取交集，屏蔽优先；策略只能在资源默认可见范围内收窄，不能越界扩大。
- 连接器说明存在冲突：白名单文字称可“额外获得”，同页又写“可见范围优先”和 allow 取交集、deny 取并集。尚无受控身份/真实保存证据能消除该冲突，后续必须明确最终策略真值表。
- 产品支持矩阵不同：例如专家/连接器页面显示 WorkBuddy 和企业智能体支持、CodeBuddy 暂不支持；自定义指令则显示 WorkBuddy 暂不支持。不能将所有资产类型视为所有客户端通用。
- 个人模型、技能、连接器各有独立企业策略；连接器还有企业级 MCP Hub 来源配置。

### 客户端配置与安全

- 内置菜单不可移除，可重命名/换图标/排序/启停；停用项不参与排序。自建菜单需要中英文名称和 HTTPS iframe 地址，目标站须允许嵌入。
- 菜单整体编辑和发布，草稿不生效；可绑定 OneID 自建应用用于 iframe 免登。新建对话页也区分草稿/发布，固定 AI 风险前缀不能关闭。
- 页面声称：助理配置约 5 分钟同步；分享配置约 1 分钟；安全策略约 10 分钟或客户端重启后立即生效；网盘容量新规则约 3–5 分钟。以上是产品说明，**不是本轮实测延迟**。
- 助理总开关会关闭本地助理、云助理和企业智能体入口。移动渠道关闭不自动停用既有自动化任务，需另行停用任务。
- 安全策略多条命中时，只选数字优先级最大的整条策略，不合并所有策略。成员可叠加更严格配置，不能突破企业基线。
- 分享的发布范围与协作范围独立；即便企业允许全网，客户端默认仍为组织内。实体文件分享开关及微信/企微渠道另行控制。
- IP 白名单支持逗号分隔与 CIDR；页面将空值解释为全部允许，单独 `127.0.0.1` 解释为全部禁止。这是需显式兼容的产品规则，不是通用网络语义。

### 凭据、任务、评测与计量

- 凭据页面声明加密存储并由代理在运行时注入。浏览器侧无法验证密钥算法、密钥管理、解密边界或后端日志脱敏。
- 自动化可关联已发布 Agent 或自定义模型/指令，支持周期/间隔/单次、生效区间、飞书 Bot/Webhook 推送。页面预览使用含秒位的 Cron；时区、夏令时、重叠和重试语义仍需确认。
- 页面宣称单次执行最长 30 分钟；本轮未触发任务，未测超时/取消/重试/最终状态。
- 评测位于同源 `/hubble-eval/` iframe，具有任务、数据集、报告、快速评测、AI 对话评测入口。当前显示创建专用 API Key 的确认弹窗；未确认或创建，因此执行链路待验。
- 计量周期可选订阅生效日切片或自然月；成员/部门/应用限量、Credit 与最终账单对账要单独实现。实时成本图表本身提示以订阅用量明细为最终计费依据。
- 全局提示词页同时保留“应用到所有对话”的旧说明及“目前不再对客户端生效”的提示；适配时不能默默启用旧注入行为。

## 接口证据与静态证据

观察到的自有产品接口主要通过 `/console/enterprises/{enterpriseId}/...`，组织/角色微前端还请求 `/oneid/admin/...`。例如模型、技能、客户端安全、分享配置、订阅用量和观测均有实际读取记录。

发布代码包含对应写调用候选，例如客户端安全策略创建/更新/启停/删除、模型创建/测试、分享配置更新等；一些代码路径带 `/api/console/...`，而网络实际看到 `/console/...`。应根据真实传输和封装层逐个核对，不能直接批量把静态路径当作生产 HTTP 合同。

[静态台账](static-inventory.json)为每一条记录保留文件 SHA-256、行列及字符范围，并保留路径原表达式。对顶层简短函数展开的路径仍标记 `candidate-expansion`；动态参数、作用域和条件路由不能据此获得运行证明。

## UWork 复用与待迁移点

源码已有企业身份适配、加密会话存储、扫码 nonce/组织绑定、跨窗口同步、网关模型/用量同步和相关 UI hooks。身份合同令牌不进入 Renderer 视图；这些边界应保留。

当前网关客户端还会生成/揭示 API Key 并配置 Provider，因此仅复用现有实现不能满足长期上游密钥完全留在后端的目标。自有后端应控制模型访问，终端只持有可撤销、受作用域约束的凭据；具体迁移需在模块规格中确定。

隔离适配副本没有继承原工作区未提交改动，也尚无业务代码变更。完整 `pnpm typecheck`、`pnpm lint`、架构检查和交互回归要在实际修改后执行；本轮没有将未运行的客户端检查写成通过。
