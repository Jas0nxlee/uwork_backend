## 修复与回归

1. 运行及会话页面提交 q，但后端未将其加入查询。新增可见元数据的字面子串过滤、租户和状态/会话条件相交、总数与分页一致及唯一排序；不解密或检索运行正文。两项真实 TCP HTTP 回归覆盖非匹配、ID 大小写、字面通配字符、跨租户、条件组合和分页；真实浏览器修后复测通过。
2. CLI 的 once 信号监听器在调用时消失，Agents SDK 的异步信号处理可能判定没有其他关闭所有者，提前退出并遗留数据库租约。改用保留监听器与单次关闭 Promise，等待 app.close 完成再退出。真实 CLI 子进程 SIGINT/SIGTERM 回归均退出 0、租约行数 0；实际主实例 SIGTERM 关闭亦释放租约，随后立即重启成功。命名空间保护窗口未缩短，未强删租约。

修前失败日志与修后证据分别保留。最终后端 144 项测试全部通过，失败/跳过/取消均为 0；typecheck、lint、format:check、ledger:check 和生产 build 通过。两处修复分别由其他 agent 复核，无新增依赖或数据库迁移。
