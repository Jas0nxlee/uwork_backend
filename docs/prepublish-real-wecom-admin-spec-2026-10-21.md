# 真实企微管理端 UI 联动

在主库的一致性独立副本启动原 Fastify 后台与正式管理端静态资源，使用独占 Chrome profile/browser-harness。主库只读，worker关闭，不对主库成员执行变更。测试实际登录表单、企业与企微配置查看、两次原“同步通讯录”按钮、成员与部门页面以及退出。

后端调用现有真实企微 provider；不替换HTTP响应或前端状态。每次成功通知必须对应一个实际成功同步请求，第二次同步前后身份摘要相同，角色/席位不变。列表按真实返回数量核对，但输出只保留数量/摘要，不保存通讯录正文或页面截图。凭据只在内存及0700临时根的0600控制文件中使用，退出后删除根；响应不得泄露真实Secret。

该测试证明真实企微通讯录→UWork后台→管理页面的消费链路，不等于企业成员OAuth扫码/回调或客户端企微身份领取。原OAuth自动操作策略拒绝不绕过。每个新profile单独留证，所有自有进程与端口关闭后才宣告成功。
