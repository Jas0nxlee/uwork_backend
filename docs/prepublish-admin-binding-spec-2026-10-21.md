# 原企微应用配置与两处身份绑定入口

独立binding模式使用全新合成企业/账号/外部ID和随机Vault凭据，不访问真实企微OAuth，不合并任何真实账号。原企业与企微“配置应用”表单保存成功后，原HTTP和SQLite一致；原再次尝试更换CorpId应409且原配置不变。

原Settings“绑定身份”为成员A绑定合成外部ID，再同样绑定一次幂等；原成员行“绑定企微身份”为B绑定A已占用ID应409 IDENTITY_BOUND且A/B和凭据/会话/角色席位不变。原B行绑定另一个ID后reload两行保持，原A行表单预填原ID。只比较允许变化的external_id，其余用户/成员字段全行不变。模型/ledger0，三次成功绑定审计，浏览器两次应用写入/四次绑定分别匹配。

此例验证管理映射和冲突保护，不能代称真实成员SSO；真实企微API/原Vite同步另由real-wecom-admin-v8记录。
