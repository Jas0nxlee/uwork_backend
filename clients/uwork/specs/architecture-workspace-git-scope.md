# 内置工作区的 Git 变更范围

客户端迁入父仓库 `clients/uwork/` 后，不再拥有独立 `.git`。架构工具仍以当前客户端工作区为模块根；既有 `changedFilesFromGit` 是变更路径集合的唯一所有者，不新增平行的路径映射或弱化策略。

`git diff` 必须在当前工作区范围内返回相对路径，排除父仓库其他目录的改动。未跟踪文件保持既有 NUL 分隔和工作区相对语义。空格、中文路径不可被转义或拆分；同一规则适用于独立 checkout 和父仓库中的子目录。检查失败仍向上报错，不静默改为空集合。

父仓库 Git 变更 → 当前工作区相对路径集合 → 既有模块/依赖映射 → 既有架构检查。

验收使用真实临时父 Git 仓库：已跟踪的内部修改、内部新增文件都进入集合；外部修改和外部新增文件都不进入；客户端本身没有嵌套 `.git`。不更新架构 baseline，不改变生产应用状态或接口。
