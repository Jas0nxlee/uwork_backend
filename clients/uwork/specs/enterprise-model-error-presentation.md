# 企业模型不可用提示

2026-10-20 Linux 原包实测：撤销席位后原发送被拒，供应商和账本无增量，但界面只提示稍后重试，不能引导用户处理当前授权问题。

继续由原 enterpriseModelErrorCopy 按稳定精确码映射现有 chat.error.enterpriseServiceUnavailable。该映射涵盖 policy/model/relay unavailable，不能仅凭这些码断言唯一原因是席位撤销或服务故障。共享提示应要求检查企业登录、席位和权限；这些均正常时再稍后重试。两种语言同步，不修改原始错误详情、错误码、请求、重试或授权所有者。

原精确码回归保持通过，类型/Lint/架构/格式通过；新正常 Desktop 构建及原 Linux 打包态重验：允许发送实际两调用/本人两 settled/44 Credit，撤席位后原发送显示含授权检查指引的错误，且模型/账本不增加。原包失败截图和日志保留。此改动为静态文案修正，不新增行为分支或测试专用产品接口。
