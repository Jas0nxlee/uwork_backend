# macOS 窗口辅助程序构建

窗口辅助程序是 Desktop 原生运行时资产。构建脚本拥有生成文件，消费者仍从 `resources/macos-window-bounds/zcode-window-bounds` 读取，运行时接口不变。

构建复用 `getTargetPlatform()`，与 Desktop 的 `ZCODE_TARGET_OS` / `ZCODE_TARGET_ARCH` 选择一致。每个发布包只要求自身目标架构；ARM64 包不得因 x86_64 Swift 支持库缺失而丢失已经可编译的 ARM64 辅助程序。未显式选择时使用宿主架构。构建文件加 `-arm64` / `-x64` 后缀，由打包配置选择对应源文件并保持包内固定名称；避免同 checkout 两种架构互相覆盖。仅宿主架构另更新开发态的无后缀路径，跨架构构建不得覆盖该文件。

编译先写本次唯一暂存路径，成功后原子替换固定输出。失败或缺少 swiftc 时维持既有可选能力降级，但移除可能属于其他目标的旧输出，清理本次暂存文件并明确警告；不得把旧架构文件包装成成功结果。非 macOS 构建跳过。辅助程序的权限及网络行为不变。

验收：arm64 与 x64 各自仅编译目标架构；失败后无过时输出及暂存残留；本机 ARM64 实际 Swift 编译、Mach-O 架构验证及运行通过。没有对应工具链时不声称 x64 实机验证。
