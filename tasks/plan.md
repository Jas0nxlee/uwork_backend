# 后端实施计划

2026-10-14。用户授权按项目指引自主完成；规格及实现决策在仓库留存，不增加交互审批。

## 实施决策

- Node.js 24 LTS + TypeScript + Fastify；SQLite WAL，单实例部署，事务承担额度/发布/任务的并发一致性。数据库文件必须位于本机持久卷，禁止网络文件系统和多副本写入。
- 模块沿用 CAPABILITY-MAP 的 ID；共享 DB/错误/事件/请求协议为基础合同，业务状态由对应模块独占写入。
- 本地组织管理作为自有扩展；企微 OAuth 和同步为独立接入。没有真实企业配置时明确返回不可用，禁止模拟扫码成功。
- 模型使用 OpenAI-compatible 上游；长期密钥 AES-256-GCM 加密，只在服务端代理调用。终端使用可吊销、绑定成员和组织的短期凭据。
- 资源可见范围先过滤，多条 allow 取交集，deny 优先；连接器也采用此保守定义。安全策略选最高优先级完整规则，成员只能收紧。
- Credit 定义为整数计量单位，由每模型输入/输出 token 单价决定；预留最大消费并在终态结算。不能把本地 Credit 称为供应商账单。
- Runtime 使用固定 SDK、自有 Gateway 计量端口、专用 Docker engine 和受控 MCP 工具，不执行宿主 shell。MCP 通过共享 vault/SSRF 网络通道，分派后未确认结果保留 uncertain，不误报远端已停止。调度使用 cron-parser，持久化下次运行及唯一触发键，重启不自动重放已执行副作用。
- 网盘/支付/外部云沙箱等需真实服务资源；提供能力声明及网盘适配，自有 Docker 隔离资源已实际验证，不虚构外部订阅、付款或云供应商环境。

## 切片顺序与验证

1. identity/directory/access-control：初始化、登录、会话/终端密钥、组织切换、成员/部门/角色、租户隔离，API 行为测试。
2. credential-vault/model-gateway/entitlements：加密、可见范围、模型测试/代理、账本/并发限量，受控 HTTP 上游验证。
3. ai-assets/client-policy：版本/分类/审核/分发、草稿/发布、菜单/助理/分享/安全/IP、客户端快照；策略矩阵测试。
4. agent-runtime：Agent 版本、Session、执行/取消/重启终态、自动化/Webhook、评测，真实本地受控上游集成测试。
5. telemetry/external-integrations：审计、Trace、对话、指标、CSV、留存清理和网盘适配；分页/导出/脱敏验证。
6. admin-web/uwork-client：同源管理 Web 和自有网关客户端合同，真实 UI 操作，按适配仓库架构合同集成。
7. 构建与交付：锁定安装、类型/测试/格式、容器、部署/备份/恢复/验收台账；真实企业扫码和供应商验证独立标注。

## 验证边界

受控测试证明自有实现行为，不证明 WorkBuddy 服务端契约，也不替代真实企微逐组织扫码、真实供应商、三平台安装、支付或云沙箱验收。所有限制记录在 docs/acceptance.md。
